# Duel Games

## Documentation
This documentation provides an overview of the Duel Games repository, including features, installation instructions, deployment guide, and game controls.

## Features
- **User-Friendly Interface**: Designed for ease of use.
- **Multiplayer Options**: Play with friends or against AI.
- **Customization**: Options to customize game parameters.

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/MvMSOLO/duelgamess.git
   cd duelgamess
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up the environment variables:
   Create a `.env` file in the root directory and add the necessary environment variables.

## Deployment Guide
To deploy the application, follow these steps:
1. Build the application:
   ```bash
   npm run build
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Access the application at `http://localhost:3000`

## Game Controls
- **Arrow Keys**: Move character.
- **Space**: Attack.
- **Esc**: Pause the game.
